# License Constellation under AGPL-3.0

Constellation uses AGPL-3.0 because its value can be delivered over a network without distributing a binary. The license keeps modified hosted management planes available to their users.

Jochona Client and Jochona Host keep their existing GPL-compatible licenses. Protocol specifications and interoperability do not require a shared repository or a Jochona-operated service.
